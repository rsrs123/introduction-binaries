# Introduction — Binaries

Public distribution channel for **Introduction IDE**. Source code at
[rsrs123/introduction](https://github.com/rsrs123/introduction) (private until launch).

## Install

### macOS / Linux

```bash
curl -fsSL https://raw.githubusercontent.com/rsrs123/introduction-binaries/main/install.sh | bash
```

### Windows

Descarga el `.zip` del último [release](https://github.com/rsrs123/introduction-binaries/releases/latest), descomprime, y doble-click `Introduction.exe`.
